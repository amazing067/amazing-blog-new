# 연관 키워드 → 핵심 키워드 전환: 분석 및 차이

## 1. 연관 키워드 vs 핵심 키워드 — 무엇이 바뀌었나

### 1.1 정의

| 구분 | 연관 키워드 (이전) | 핵심 키워드 (현재) |
|------|---------------------|---------------------|
| **목표** | SearchAd가 주는 “연관/확장” 키워드 중 점수 높은 5개 | **문서를 대표하는** 상품+의도/타깃 5개 |
| **후보 소스** | SearchAd 연관키워드 전부 (암보험비갱신형, 고액암종류, 항암치료비용, 유사암, 암보험비교사이트 등) | SearchAd 결과 중 **핵심만** 필터 + 부족분은 **상품군별 템플릿** |
| **선발 기준** | 점수 + 버킷(product/intent/persona) 다양성, 2·3차에서 버킷 없는 것도 허용 | **core 버킷 있는 것만** 선발, 5개 미만이면 **템플릿으로만** 보강 |

### 1.2 “핵심” 판별 규칙 (코드)

- **핵심으로 인정**: 다음 중 하나
  - 키워드 = 상품명 (예: `암보험`)
  - 키워드에 **상품명(또는 relevanceTerms) 포함** + **의도어** (보험료, 보장, 가입, 가입조건, 비교, 추천)
  - 키워드에 **상품 포함** + **타깃** (10~70대, 직장인, 주부 등)
- **롱테일 핵심키워드** (가산·우선): 상품 + 타깃 (예: `50대 남자 암보험`, `50대 암보험 보험료`) → 경쟁 적고 노출·전환 유리, 선발 시 우선.
- **핵심에서 제외**
  - 비교사이트/비교몰/비교앱/비교어플 포함 → core 아님
  - 상품만 있고 의도·타깃 없음 (예: 암보험비갱신형, 고액암종류, 항암치료비용, 유사암) → **연관/서브토픽**으로 간주, core 아님

### 1.3 동작 시나리오 (암보험 기준)

**SearchAd가 주는 상위 예시 (기존 로그 기준)**  
`암보험`, `암보험비갱신형`, `고액암종류`, `항암치료비용`, `유사암`, `암보험비교사이트`, …

**연관 키워드 방식 (이전)**  
- 위 전부 후보 → 스코어·버킷으로 5개 선발  
- 결과 예: `암보험`, `암보험비교사이트`, `암보험비갱신형`, `고액암종류`, `항암치료비용`  
- 특징: 검색량·연관성 좋은 “암 관련”이지만, **문서 역할**(보험료/보장/가입 등)은 보장되지 않음.

**핵심 키워드 방식 (현재)**  
- **core만** 후보: 위 목록 중 `암보험`(상품명 자체)만 core.  
  - `암보험비교사이트` → 비교사이트형이라 core 제외.  
  - `암보험비갱신형`, `고액암종류`, `항암치료비용`, `유사암` → 의도/타깃 없음 → core 아님.  
- SearchAd에서 core 1개만 나옴 → 나머지 4개는 **템플릿**으로 채움.  
- 결과 예: `암보험`, `암보험 보험료`, `암보험 보장내용`, `암보험 비교`, `암보험 가입`.  
- 특징: **문서 목적에 맞는** “상품 + 의도” 5개로 고정.

### 1.4 무엇이 “많이” 바뀌는가

| 항목 | 연관 키워드 (이전) | 핵심 키워드 (현재) |
|------|---------------------|---------------------|
| **최종 5개 구성** | 연관/서브토픽 혼합 (비갱신형, 고액암종류, 항암치료비용, 비교사이트 등) | 상품명 + 보험료/보장/비교/가입 등 **역할이 드러나는** 5개 |
| **문서 적합성** | “암보험 관련”이면 OK → Q&A 본문에 넣었을 때 어색한 표현 가능 | “이 글이 다루는 주제”를 그대로 말해주는 키워드 세트 |
| **검색량 의존도** | SearchAd 검색량 높은 연관어가 많이 포함 | SearchAd는 “핵심 후보가 몇 개 나오는지”만 쓰고, 부족분은 **고정 템플릿**으로 채움 |
| **안정성** | 상품/시장에 따라 연관어 구성이 달라져 세트가 들쭉날쭉 | 상품군별 템플릿으로 **항상 동일한 역할**의 5개 보장 가능 |
| **비교사이트/서브토픽** | 점수만 높으면 5개 안에 포함 가능 | 비교사이트형은 core 제외, 서브토픽(고액암종류 등)도 core 아님 → **최종 5개에 안 넣음** |

요약: **“연관 키워드”는 “검색 수요가 큰 암 관련어 5개”**, **“핵심 키워드”는 “이 문서가 다루는 주제 5개(상품+의도/타깃)”**로 바뀐다.

## 2. 분석 관점 정리 (PR + CS)

### 2.1 문제 재정의(PR)

- **겉보기**: “키워드가 이상하다 / 덜 맞다.”  
- **재정의**:  
  - 이전: “검색량·연관성 좋은 키워드”를 뽑고 있어서, **문서 역할(보험료/보장/가입 등)과는 어긋날 수 있음.**  
  - 전환 후: 목표를 **“연관어 5개”가 아니라 “문서를 대표하는 핵심키워드 5개”**로 바꿈 → 선발 기준이 “역할”로 맞춰짐.

### 2.2 복잡성 해결(CS) — 층별로 보면

- **검색·SearchAd hint**: 변경 없음. (이미 상품군 정리·긴 문장형 제거 완료.)
- **키워드 후보 풀**: 동일 (SearchAd 15개 등).
- **선발 층**:  
  - 이전: 풀 전체에서 점수+버킷으로 5개 → **연관/서브토픽 포함 가능.**  
  - 현재: **core만** 필터 → 그중 5개, 부족하면 **템플릿** → **항상 “상품+의도/타깃” 형태.**

즉, **변경은 “선발 층”에만** 있고, “얼마나 달라졌는지”는 전부 여기서 나온다.

## 3. 아직 남는 핵심 병목 (분석 요약 반영)

핵심키워드 전환으로 **키워드 세트**는 “문서 목적에 맞는 5개”로 정리됐다.  
아래는 그대로 두고 가져간 분석 요약이다.

1. **생성 사실성**  
   입력에 없는 구체 수치/조건(1억, 100세, 30.9% 할인 등)을 질문/답변에 넣지 않도록 하는 가드레일이 **아직 약함**.  
   → 프롬프트에서 “수치/조건 등급(A/B/C)”과 “확정형 금지”를 더 강하게 넣는 쪽이 유리.

2. **제목/길이/포맷**  
   제목이 길고 어색·잘림, 답변·댓글 길이 불균형(고객 59자 등).  
   → 제목 전용 규칙(길이·수치 금지 등) + 댓글 최소 길이 등 **후처리/정형화**가 필요.

3. **장르 일관성**  
   “보험 정보글 + 카페 고민글 + 비교몰형 문구”가 섞임.  
   → 카페 질문글은 “고민/불안/받은 느낌” 중심으로 제한하고, 비교몰/어플 문구는 제목·첫 문단에서 제한하는 식의 **문서 목적 분기**가 필요.

## 4. 테스트 관점에서 기대되는 차이

동일 입력(암보험, 50대 남자 직장인, 동일 worry/selling)으로:

- **연관 키워드 (이전 로직)**  
  - 로그처럼 `암보험`, `암보험비교사이트`, `암보험비갱신형`, `고액암종류`, `항암치료비용` 등이 나올 수 있음.
- **핵심 키워드 (현재 로직)**  
  - SearchAd에서 core는 보통 `암보험` 1개 수준 → 나머지는 템플릿.  
  - 최종: `암보험`, `암보험 보험료`, `암보험 보장내용`, `암보험 비교`, `암보험 가입`.

실제 로그에서 확인할 것:

- `[Q&A 생성] 핵심키워드 후보(SearchAd): N개 [...]` → N이 0~2 수준이고, `암보험` 또는 `암보험 보험료` 등만 나오는지.
- `[Q&A 생성] 핵심 키워드 5개: [...]` → 위와 같은 “상품+의도” 5개가 나오는지.

이렇게 되면 **연관 키워드에서 핵심 키워드로 바꾼 뒤 “뭐가 많이 바뀌었는지”**는, 위 표와 이 시나리오로 설명 가능하다.
