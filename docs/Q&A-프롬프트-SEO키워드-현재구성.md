# 네이버 카페 Q&A 블로그 프롬프트 — SEO/키워드 현재 구성

현재 **질문 생성**·**답변 생성** 프롬프트에서 SEO·핵심키워드와 관련된 부분만 정리한 문서입니다.  
다른 곳에 “구글 커스텀 API + 하나 더 뭘 쓰면 좋을지” 물어볼 때 아래 내용을 그대로 복사해 쓰면 됩니다.

---

## 1. 현재 데이터 소스 (키워드/검색 관련)

| 구분 | 용도 | 출처 |
|------|------|------|
| **최신 검색 요약** (`searchResultsText`) | AI가 참고하는 “최신 정보” | **Google Custom Search API** — 여러 쿼리로 검색한 결과의 title+snippet을 모아서 불릿 요약 |
| **연관 키워드 5개** (`searchKeywords`) | 질문·답변 **본문에 반드시 포함**할 키워드 | **네이버 검색광고(SearchAd) API** 키워드 도구 — 상품명·"상품명 보험" 힌트로 연관키워드·월간검색수 조회 후 상위 5개. 미설정 시 Google Custom Search 결과에서 추출한 후보 5개 사용 |

- Google Custom Search 쿼리 예:  
  `상품명 보험료 가격`, `상품명 보험료 비교`, `상품명 장점 특징`, `상품명 특약 구성`, `상품명 보장 내용`, `상품명 후기`, `상품명 + 타겟 보험료/추천`, `상품명 + 고민/세일링포인트`
- 연관 키워드: 네이버 SearchAd API 연동 시 **네이버 월간검색수(PC+모바일) 순** 상위 5개. API 미설정/실패 시 Google 검색 결과에서 `...보험` 패턴 추출 후 보충(상품명 추천/비교/보장 내용/가입조건/보험료)한 뒤 앞 5개 사용.

---

## 2. 질문 생성 프롬프트 — SEO/키워드 관련 부분만

```
[최근 검색 요약]  ← searchResultsText 있으면 포함
- 아래 검색 요약을 근거로 최신/구체 정보를 자연스럽게 반영하세요
- 링크나 출처를 본문에 남기지 말고 내용만 녹여서 전달하세요
(실제 searchResultsText 내용)

[입력 데이터]
- 상품: {productName}
- 고민: {worryPoint}
- 설계서 내용: (있으면)
- 최근 검색 요약: (위와 동일)

- 연관 키워드 (아래 제목·본문에 반드시 포함): 키워드1, 키워드2, 키워드3, 키워드4, 키워드5  ← searchKeywords

[연관 키워드 반영 - 필수]
- 위 "연관 키워드"를 **반드시** 제목 또는 본문 글 내용 안에 넣어주세요. 문맥에 맞게 자연스럽게 문장에 녹여 넣되, 주어진 키워드가 질문 글 안에 정확히 들어가야 합니다
- 억지럽게 나열하지 말고, 문장 흐름에 맞게 자연스럽게 사용하세요

제목: [제목 작성]
본문: [본문 작성]
```

- 역할: **질문글**에 “최신 검색 맥락” 반영 + **연관 키워드 5개를 제목/본문에 반드시 포함**.

---

## 3. 답변 생성 프롬프트 — SEO/키워드 관련 부분만

```
[최근 검색 요약]  ← searchResultsText 있으면 포함
- 아래 검색 요약을 근거로 최신/구체 정보를 자연스럽게 반영하세요
- 링크나 출처를 본문에 남기지 말고 내용만 녹여서 전달하세요
(실제 searchResultsText 내용)

[연관 키워드 반영 - 필수]
- 아래 연관 키워드를 **반드시** 답변 본문 글 내용 안에 넣어주세요: 키워드1, 키워드2, 키워드3, 키워드4, 키워드5
- 문맥에 맞게 문장에 자연스럽게 녹여 넣되, 주어진 키워드가 답변 글 안에 정확히 들어가야 합니다. 억지럽게 나열하지 말고 문장 흐름에 맞게 사용하세요
```

- 역할: **답변글**에 “최신 검색 맥락” 반영 + **동일 연관 키워드 5개를 본문에 반드시 포함**.

---

## 4. “다른 곳에 물어볼 때” 복사용 문장 (추천 하나 더 붙이기)

SEO 핵심키워드 최적화를 위해 **구글 커스텀 API 말고 하나 더** 쓸 만한 걸 찾을 때, 아래 문장을 그대로 붙여서 물어보면 됩니다.

---

**복사용 문장:**

```
우리는 네이버 카페/블로그용 보험 Q&A 글을 AI로 생성하고 있고, SEO 핵심키워드를 본문에 자연스럽게 넣고 싶어요.

현재 구성:
- Google Custom Search API: 상품명·타겟 기반으로 여러 쿼리 검색 → 결과 title/snippet을 요약해서 프롬프트에 넣고, 그 텍스트에서 "...보험" 형태 연관 키워드 후보를 추출해요.
- (선택) DataForSEO: 위 후보 키워드들의 검색량을 조회해서 상위 5개를 골라 질문/답변 본문에 반드시 포함시키는 식으로 써요.

질문: Google Custom Search(또는 이와 비슷한 검색 API) 말고, "SEO용 핵심키워드/연관키워드"를 더 잘 뽑기 위해 추가로 쓰기 좋은 API·서비스 하나 추천해 주실 수 있을까요? (한국어·보험/금융 도메인, 예산은 적당히 들 수 있음)
```

---

이렇게 정리해 두면, “지금 프롬프트가 정확히 어떻게 되어 있나”와 “구글 커스텀 API랑 하나 더 뭘 쓰면 좋을지”를 다른 사람에게 같은 맥락으로 물어보기 좋습니다.
