# 리쿠르팅 콘텐츠 전략 리프레시 — 설계 (2026-06-21)

## 배경 / 목적

기존 리쿠르팅 콘텐츠(5기둥 P1~P5, 27토픽, 강점카드)는 잘 작동하나 다음이 부족:
- 시의성 소재 부재 (2026-07 GA 1200%룰 등 업계 변화 미반영)
- 감성 훅이 "공감" 수준 → "지원해볼까" 결심 유발까지 못 감
- 타깃이 한 덩어리 → 경력 설계사/신규 메시지가 섞여 흐림
- 비주얼이 v1 1종 → 다양성 약함 + AI티

**목표**: 어메이징사업부만의 시스템·교육을 강점으로, "수수료 평준화 → 시스템 있어야 산다 → 우리로 와라" 서사를 타깃 2종으로 분리해 전달. 콘텐츠 전략을 먼저 확정하고, 그 결과로 비축본을 찍어낸다.

## 범위 / 순서 (사용자 확정)

1. **콘텐츠 전략 (이 문서)** — 메시지·기둥·훅·비주얼 레시피·운영 설계
2. **비축본 생성** — 전략 확정 후 시작 (2~3주치)
3. **버튼 UI 구현** — 비축 검증 후 (admin 두 버튼)

**Out of scope (의도적 제외)**
- 무인 cron 자동 게시 — ❌ 비추 (AI 이미지 품질 사람 검수 필요)
- 기둥 구조 자체 리브랜딩 — ❌ YAGNI (P1~P5 이미 작동)
- 서버사이드 Higgsfield API 연동 — 추후 별도 프로젝트

## 섹션 ① 콘텐츠 기둥 & 메시지 핵심

### 한 줄 핵심
수수료가 평준화된 지금, 어메이징만의 교육·시스템이 진짜 차별점이다. 경력자는 넘어오고, 신규는 여기서 시작해야 산다.

### 타깃 2종 → 2버튼 구조

| | 버튼 A — 경력 설계사 영입 | 버튼 B — 신규 모집 |
|---|---|---|
| 타깃 | 타 GA·전속 설계사 | 입문·이직 희망자 |
| 핵심 메시지 | "수수료 평준화 → 시스템이 기준 → 우리 전용앱으로" | "맨손도 시스템이 받쳐줘서 산다 / 시스템 없는 곳은 신규가 먼저 무너진다" |
| 주 기둥 | P3(시스템·소득) + P5(후기) | P1(공감) + P2(진입장벽) + P5(후기) |
| 무기 | 전용앱(자동배정·30개사 비교·예외질환·실손·HIRA) | 교육시스템·온보딩 10일·AI 콘텐츠 자동화 |
| 비주얼 | 그래픽·타이포 | 날것 다큐멘터리 |
| 톤 | 냉정·논리 ("프로의 판단") | 감성·결심 (공감) |

### 어메이징사업부만의 장점 5종 (무기)
1. 교육 시스템 — 온보딩 10일, 첫 주부터 실전 도구
2. 전용앱 시스템(Server) — 고객 자동배정(지인영업 X)·30개사 비교·예외질환 전환·실손청구 조회·HIRA 진료내역·AI 보장분석
3. AI 콘텐츠 자동화(Blog) — 블로그·카페·카드뉴스 자동 생성
4. 검사 기반 영업(Brain) — 고객이 먼저 상담 신청
5. 외주 0, 전부 직접 만들어 하나로 연동 ← 복제 불가 차별점

### P3 "시스템=생존" 3단 서사 (뉴스 통합)
별개 기둥 아님. P3 안에 하나의 서사 3단 (캐러셀 1세트 또는 3카드):

| 단계 | slug | 훅 | 사실 근거 |
|---|---|---|---|
| ① 평준화 | `p3-cap-equalized` | "2026년 7월, 이제 어느 GA를 가도 수수료 상한은 똑같습니다" | 1200%룰 GA 확대 (금융위 확정) |
| ② 생존조건 | `p3-system-or-out` | "수수료가 같아진 지금, 시스템 없는 곳은 못 버팁니다" | 중소 GA 설계사 16%↓·이탈 가속 / 수수료 차별화 종료 |
| ③ 우리 시스템 | `p3-our-apps` | "그래서 우리는 직접 만들었습니다" | amazing-biz-server 전용앱 기능들 |

> "오래가는 설계사가 이긴다(분급제 retention)" 앵글은 폐기 — 시스템 연결이 약함. "시스템 있어야 산다"로 대체.

### 회전 비중
P1 공감 35% / P3 시스템·소득 25% / P5 후기 20% / P2 진입장벽 12% / P4 라이프 8%

## 섹션 ② 감성 훅 강화 규칙

### 공통 5규칙
1. 1초 안에 멈추게 (첫 줄이 전부)
2. 구체 > 추상 (숫자·장면)
3. 첫 줄에 답 주지 마라 (궁금증 → 다음 슬라이드)
4. 타깃 호명 ("7년차라면" / "퇴사 검색해봤다면")
5. 금지선: 소득 단정("월 ○○") · 럭셔리 플렉스 · 타사 실명 (이것만 피하면 톤은 과감하게)

### 트랙 A — 경력자 (냉정·논리)
훅 공식: `[업계 사실·변화] + [되묻는 질문]` → 손실회피·자존심
- "2026년 7월, 이제 어느 GA를 가도 수수료 상한은 똑같습니다."
- "수수료가 같아지면, 남는 건 '뭘로 일하느냐'뿐입니다."
- "지인 리스트 다 쓰고 나면, 그다음은요?"
- "10년 차인데, 아직도 고객을 직접 찾으세요?"

결심 동선: 사실 → 손실회피 → 시스템 증거 → "판단은 직접" CTA

### 트랙 B — 신규 (감성·결심)
훅 공식: `[현타 공감 장면] + [전환 가능성 암시]` → 공감·희망
- "월요일마다 죽고 싶던 직장인이었습니다."
- "열심히 일해도 통장은 그대로. 이게 맞나 싶었어요."
- "지인 영업 때문에 안 했어요 — 근데 안 해도 되더라고요."
- "맨손으로 시작했는데, 첫 주부터 손에 도구가 있었어요."

결심 동선: 공감 → "나도 될 수 있다" → 시스템이 받쳐줌 → "부담 없이 물어보세요" CTA

### CTA (트랙별)
- A: "시스템 보고 판단하세요 — DM '시스템'"
- B: "부담 없이 물어보세요 — DM '어메이징'"

## 섹션 ③ 비주얼 레시피

### 공통 철칙
1. 얼굴 없음 — 손·사물·뒷모습·화면만
2. 한글 텍스트 이미지에 안 넣음 — 배경만 생성, 글자는 RecruitStyle 템플릿/프리미어에서 얹음
3. 9:16 기본 / 4:5 보조, 프롬프트 끝 항상 `no text, no letters, no logo`

### 트랙 B — 신규 (날것 다큐멘터리)
- 모델: `soul_2` (UGC 리얼리즘 1순위)
- 소재: 창가 노트북·식은 커피·지하철 손잡이·퇴근길·책상 위 사원증
- 키워드: `candid, shot on iPhone, natural light, slightly grainy, imperfect framing, no retouching, muted cool tones`
- 금지어: cinematic, editorial, premium, perfect skin, dramatic light, heavy duotone (← AI티)

### 트랙 A — 경력자 (그래픽·타이포)
- 모델: `recraft-v4-1` (vector/utility, 브랜드색 hex 잠금 #1E5BFF·#0E9AA7) / 사진톤 필요시 `nano_banana_pro`
- 소재: 추상 시스템 그래픽, 앱 대시보드 느낌(글자 없는), 데이터 흐름, 30개사 비교 모티프
- 느낌: 깔끔·테크·신뢰

### 브랜드 색
- 이미지 안에선 은은하게(muted) / 진짜 브랜드색은 텍스트·템플릿 레이어에서

### 후처리
- 선택본 → `upscale_image`로 디테일·그레인 보강 (B는 그레인 더, A는 선명하게)

### 워크플로
```
힉스필드 배경(글자X) → RecruitStyle 템플릿(한글 훅·CTA·브랜드색·심의)
                     또는 → 프리미어(릴스)에서 한글 얹기
```

## 섹션 ④ 비축 연계 & 운영

### 6단계 흐름
```
① 토픽 선택  — audience(A/B)+pillar+freshness 태그로 풀에서
② 카피 생성  — 기존 generator(코드) + recruit-lint 자동 차단
③ 배경 생성  — 힉스필드 트랙별 레시피 (대화창에서 배치)
④ 조립       — 배경 + 한글 카피를 RecruitStyle 템플릿에 합쳐 캡처
⑤ 사람 검수  — AI티·이상한 컷 골라내기 (무인 cron 안 가는 이유)
⑥ 비축       — 통과본 라이브러리에 쌓고 매일 게시
```

### 첫 비축 배치
- 분량: 2~3주치 (일 1게시 기준 약 20장)
- 트랙 비중: 신규 B 60% / 경력자 A 40%
- 기둥 회전: 섹션 ① 비중대로
- 뉴스 3연작(1200%룰): freshness `2026-07` → 우선 포함, 7월 후 후순위

### 운영 규칙
- 충전식 (라이브러리 떨어지면 보충, 무인 cron 아님)
- 두 버튼 = 트랙 A/B 생성 진입점 (지금 수동, 나중에 admin 버튼 구현)
- 신선도 관리: 뉴스토픽 만료 시 교체, 상시 토픽 재사용

### 검수 게이트 기준
얼굴 / 한글 깨짐 / 손가락·사물 이상 / 브랜드 쿨톤 / 심의(소득 단정·럭셔리) → 하나라도 걸리면 탈락·재생성

### 배치 생성 현실
Higgsfield 동시 제출 시 연결 끊김 → 하나씩 제출 후 폴링 방식으로 순차 배치.

## 부록 — 리서치 팩트 (2026-06 조사)

### 2026-07 GA 1200%룰
- 2026.7.1부터 GA 소속 설계사도 초년도 수수료+시책+정착지원금 합계 월납 1,200% 상한 (금융위 보험업감독규정 개정, 2026.1 확정)
- 기존 실수취 약 2,300% 수준 → 초년도 수입 구조적 압축
- 2027.1 4년 분급제 / 2029.1 7년 분급제 — 선지급 폐지, 유지율 연동 소득
- 정착지원금도 1200% 한도 포함 → 대규모 지원금 불가, 금감원 대형 GA 49곳 자율점검(2026.4)
- 출처: 금융위(fsc.go.kr/no010101/86050), 보험저널(insjournal.co.kr 26855·29922·30413 등)

### 업계 구조
- 설계사 평균 월소득 338만원, 하위 20% 연 2,400만원 미만 — 양극화 (2024말, 생보협회·한국보험신문)
- 2026 GA채널 성장 +1.3% 정체, 보험사 물량목표 하향
- 중소 GA(100인 미만) 설계사 16%↓ / 대형 GA 25%↑ — 인프라 없는 곳 이탈 가속
- → 1200%룰 후 수수료 차별화 종료 = 교육·시스템·리드·유지지원이 선택 기준

### 어메이징 시스템 (근거: docs/amazing-division-reference.html, lib/content/recruit-strengths.ts)
- 5시스템: Prime(홈/채용)·Server(보장분석·CODEF 35개사·30개사 비교·HIRA·자동배정·앱)·Blog(콘텐츠 AI)·Brain(검사+시뮬)·Check(조직)
- 강점 팩트뱅크 8개 + 캡스톤 "외주 0, 전부 직접 만들어 하나로 연동"
- Work(통합로그인)은 개발 보류 → 메시지 제외
