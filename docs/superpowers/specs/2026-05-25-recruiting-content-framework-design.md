# 어메이징 사업부 리쿠르팅 콘텐츠 프레임워크 — 설계 문서

- **작성일**: 2026-05-25
- **목적**: 보험설계사 리쿠르팅(모집)을 위한 인스타그램·블로그·릴스 콘텐츠를 기존 카드뉴스 자동화 시스템 위에 **별도 트랙**으로 올린다.
- **상위 프로젝트**: Content Automation Hub (`2026-05-02-content-automation-hub-design.md`)
- **핵심 차별점**: 보험 콘텐츠는 광고심의 대상이라 수치·금액·보험사명·단정 표현을 전면 차단하지만, **리쿠르팅은 협회 광고심의 면제** → 규칙을 풀되 직업안정법·플랫폼·인식 리스크만 가드레일로 막는다.

## 1. 확정된 정책 결정

브레인스토밍에서 사용자가 확정한 사항.

| 항목 | 결정 |
|---|---|
| **타깃** | 폭넓게 믹스 (2030 신입·이직 / 경력 설계사 / 주부·N잡) — 시리즈별로 나눠 공략 |
| **톤** | 공감·자극 + 성공·플렉스(**리프레이밍 버전**) + 진정성·스토리 |
| **회사 강점(콘텐츠 무기)** | ① 높은 수수료·시상 ② 교육·정착 시스템 ③ DB·고객 리드 제공 ④ 자유근무 + 디지털 툴. **정착지원금은 없음(제외)** |
| **포맷** | 카드뉴스(설득) + 블로그(검색·신뢰) + 릴스(도달) — 3트랙 |
| **구현 방식** | 기존 카드뉴스 시스템에 `contentType='recruiting'` 분기 추가, **어드민에 리쿠르팅 전용 탭 신설** |
| **플렉스 처리** | 럭셔리·수익보장 제거, "현실적 성장 스토리 + 조건부·범위 수치"로 리프레이밍 |

## 2. 트렌드 분석 요약 (전략 근거)

2026-05-25 도메인 리서치 결과. 출처는 11절 참조.

- **알고리즘 신호 순위**: DM 공유 > 저장 > 시청 완료율. 좋아요는 거의 영향 없음. → 콘텐츠 마지막에 **공유 유발 문구** 필수.
- **포맷 역할 분업**: 릴스 = 신규 도달(낯선 사람 유입), 캐러셀 = 설득(저장·재노출), 스토리·DM = 관계·전환. 캐러셀은 슬라이드 재노출로 릴스 대비 노출 기회 3배.
- **후킹 공식**: "구체 수치 + 역설 + 타깃 호명". 일반 주장("성공하세요") ❌.
- **해시태그 5개 상한** (인스타 공식 정책). 대분류1 + 중분류2 + 틈새2.
- **퍼널**: 릴스 유입 → 팔로우 → 캐러셀 설득 → 블로그/세미나 → **자기선발 지원**. 직접 "모집합니다"보다 끌어당기는 구조가 정석.
- **2030 인식**: 보험설계사 기피(소득 불안정·"보험쟁이" 낙인·다단계 연상). 2025년 1,400억 GA 설계사 폰지사기(인스타 "월급관리 스터디" 광고로 모집) 이후 경계 최고조. **통하는 메시지 = 시간 자율성 + 전문성 성장 경로 + 현실적 소득**. **거부 트리거 = 고수익 보장·럭셔리 인증.**
- **블로그/인스타 분업**: 인스타는 짧은 후킹·도달, 블로그는 긴 정보·검색 유입·신뢰 축적 → 인스타가 블로그로 유도.
- **타이밍**: 목요일 밤 10시 전후 DM·게시 반응률 최고(재테크·보험 업종 기준).

## 3. 콘텐츠 전략

### 3.1 퍼널

```
[릴스] 낯선 사람 유입 → 팔로우 → [카드뉴스] 설득(저장·DM공유) → [블로그] 검색·신뢰·깊은 정보
                                                  ↓
                                  DM / 무료 세미나 → 스스로 알아보고 지원(자기선발)
```
- 인스타 프로필 링크 → 블로그 / 블로그 글 끝 CTA → DM·세미나
- 직접 모집 ❌ → 끌어당겨 본인이 지원하게 ✅

### 3.2 콘텐츠 기둥 5개 (시리즈 로테이션의 뼈대)

4개 무기를 5개 기둥으로 전개. 각 기둥 = 톤 × 타깃 × 무기 매핑.

| # | 기둥 | 톤 | 타깃 | 쓰는 무기 | 후킹 예시 |
|---|---|---|---|---|---|
| **P1** | "왜 안 떠나?" (유입·진입점) | 공감·자극 | 2030·주부 | (강점 노출 전) | "월요일마다 죽고 싶던 직장인 특 (저였음)" |
| **P2** | "맨땅 영업 안 해도 됨" (진입장벽 해소) | 정보·진정성 | 신입 | 교육·정착 + DB·리드 | "보험영업=지인 다 잃는 거 아님? 요즘은 회사가 고객을 줍니다" |
| **P3** | "여기선 이렇게 번다" (소득) | 성공·**리프레이밍** | 경력·이직 | 높은 수수료·시상 | "같은 일 하는데 왜 누군 더 가져갈까 — 수수료 체계 차이" |
| **P4** | "이렇게 일한다" (신뢰 최강) | 진정성·브이로그 | 믹스 | 자유근무 + 디지털 툴 | "출근 안 하는 평일 오전 루틴" / "AI가 콘텐츠 만들어주는 보험영업?" |
| **P5** | "진짜 사람들" (전환) | 스토리·후기 | 믹스 | 사람·문화 | "대기업 7년 다니다 GA 온 이유" |

> **P3는 가드레일 핵심 구간**: "월 ○○ 보장/확정" 절대 금지 → "성과에 따라 / 상위 사례 / 수수료 체계가 다른 이유" 같은 조건부·구조 설명으로만.

### 3.3 카드뉴스(캐러셀) 7장 구조 — 리쿠르팅용

**장수 결정: 7장** (2026-05-25 딥서치 결론). 7~10장이 저장·완주·재노출 교집합 최적점이고, 5장은 저장 유도·재노출 트리거가 약하며 "공감→신뢰→행동" 여정을 담기에 빠듯. 설득형 캐러셀은 최소 6~7장 필요.

**렌더러 비용 0**: `CardStyleRouter`(`CardStyles.tsx`)는 슬라이드 1장씩 `kind`(cover/point/closing) 기준으로 렌더링 → 장수 무관. 7장을 `cover + point×5 + closing`으로 매핑하면 기존 6개 스타일을 **0줄 수정**으로 재사용. 심의필 슬라이드는 리쿠르팅에서 미렌더, closing을 최종 CTA로 재활용.

| 장 | kind | 역할 | 내용 |
|---|---|---|---|
| 1 | cover | 후킹 | 타깃의 고통/욕구를 한 문장으로. bigStat = 개념 라벨("퇴사각", "성과형") |
| 2 | point 01 | 공감/문제 확인 | "이거 내 얘기다" (독립 재노출 슬라이드) |
| 3 | point 02 | 통념 깨기/전환점 | "근데 다를 수 있다" |
| 4 | point 03 | 강점·증거 1 | 교육/DB/시스템/자유/디지털 중 하나 |
| 5 | point 04 | 강점·증거 2 / 사람 증거 | 조건부 수치·후기 (가드레일 적용) |
| 6 | point 05 | 중간 CTA | "DM으로 하나만 물어봐도 됩니다" (완주 전 이탈 구제) |
| 7 | closing | 최종 CTA | items=[DM 문의/프로필 링크→블로그/저장], footer=공유 유발 "먼저 연락하지 않습니다" |

> 알고리즘 슬라이드 재노출 대응 → **1·2·3장은 각각 따로 봐도 후킹되게** 독립 구성. 중간 CTA(6장)는 완주 전 이탈자 구제.

### 3.4 블로그 구조 — 검색·신뢰·자기선발

- **검색 타깃 키워드**: "보험설계사 후기/단점", "GA 이직", "N잡 보험설계사", "보험설계사 신입 현실"
- **글 구조**: 검색의도 충족 → 단점도 솔직 → 우리 강점 자연스럽게 → CTA(상담/세미나)
- **자동화**: 기존 블로그/뉴스 생성 파이프라인에 리쿠르팅 주제 풀 + 가드레일만 얹으면 100% 자동

### 3.5 릴스 — 단계적 (Phase 2)

- **1단계(반자동)**: "모션 카드 릴스" — 카드 내용을 세로 영상+자막+음원으로. 얼굴 X.
- **2단계(촬영)**: 설계사 하루 브이로그 / 토킹헤드. 신뢰 최강.
- **템플릿**: "회사 다닐 때 vs 지금", "퇴사 마려운 직장인 특". 20~40초, 첫 3초 후킹, 트렌드 음원.

### 3.6 공용 규칙 (후킹·CTA·해시태그·타이밍)

- **후킹 공식**: [직군/연차] + 역설 + [결과/수치]
- **CTA**: 마지막은 행동 하나로 — DM 유도 / 프로필 링크(→블로그) / 저장 중 택1 + 공유 유발 문구
- **해시태그 5개**: 대1 `#보험설계사` + 중2 `#GA취업 #보험영업` + 틈새2 `#재테크직장인 #N잡러`
- **타이밍**: 핵심 게시·DM은 목요일 밤 10시 전후

## 4. 가드레일 (안전망) — "어떤 말이든 OK"의 현실판

협회 광고심의는 면제. 단 아래는 **자동 차단(recruit-lint)**.

| 차단 대상 | 사유 |
|---|---|
| "고수익 보장 / 월 ○○ 확정 / 무조건 / 떼돈 / 누구나 가능" | 직업안정법 제34조 (5년 이하 징역·5천만원 벌금) |
| 외제차·명품·"이달의 왕" 트로피·연봉 인증 | 2030 다단계 연상 → 거부 트리거 |
| 연락처 + 구체 수익 동시 노출 | 금소법 업무광고 경계 |
| 다단계·유사수신 연상 표현("스터디", "투자 권유") | 폰지사기 사건 연상 |

**허용 표현 (리프레이밍)**:
- 수익: "성과에 따라 / 상위 사례 / 수수료 체계가 다른 이유 / 범위"
- 연락처: "DM으로 문의" (전화번호 직접 노출 회피)
- 강점은 사실 기반으로: 교육 시스템·DB 제공·자유근무·디지털 툴은 그대로 노출 OK

> 보험 카드뉴스의 `compliance-lint`(수치·금액·보험사명 차단)와는 **완전히 다른 규칙셋**. 리쿠르팅은 수치 사용 가능하되 위 가드레일만 적용.

## 5. 기술 통합 설계 (Phase 1 구현 범위)

기존 시스템에 `contentType` 분기를 추가. 보험 트랙과 **로직·UI·DB 모두 안 섞이게** 격리하되, PNG export·편집기·비주얼 스타일은 공용 재사용.

### 5.1 데이터 모델

- `lib/content/types.ts`:
  - `ContentType = 'insurance' | 'recruiting'` 추가
  - 카드 슬라이드 `closing` variant에 **CTA 모드** 확장 (또는 신규 `cta` kind): `ctaType: 'dm' | 'link' | 'seminar'`, `ctaText`, `shareNudge`(공유 유발 문구). 심의필(`ComplianceInfo`)는 리쿠르팅에서 미사용.
  - 리쿠르팅 카드/블로그는 `compliance` 필드 비움.
- DB: 기존 `content` 테이블에 `content_type` 컬럼 추가(기본 `'insurance'`), 또는 리쿠르팅 전용 row 구분 플래그. 마이그레이션 신규 1개.

### 5.2 생성기

- `lib/content/generator-recruit-card.ts` — 리쿠르팅 카드 5장 생성 프롬프트. 톤(공감/플렉스-리프레이밍/진정성) + 기둥(P1~P5) + 가드레일을 프롬프트에 주입. closing → CTA.
- `lib/content/generator-recruit-blog.ts` — 리쿠르팅 블로그 글 생성. 검색 키워드·자기선발 구조.
- 모델: 기존과 동일(Claude Haiku). 보험 생성기와 프롬프트만 분리.

### 5.3 가드레일 lint

- `lib/content/recruit-lint.ts` — 4절 차단 규칙. `compliance-lint`와 별개.
- `lib/content/lint-config.ts`: `LINT_ENABLED`에 `recruitCard`, `recruitBlog` 토글 추가.
- 생성기 후방 안전망(sanitizer): "고수익 보장/월 ○○ 확정" 등 패턴을 조건부 표현으로 자동 치환 또는 must_fix 플래그.

### 5.4 앵글 풀 (콘텐츠 주제)

- `lib/content/recruit-topics.ts` — 기둥 P1~P5 × 톤 × 타깃 매핑된 **앵글 30개** 풀. `Topic` 유사 구조 + `pillar`, `tone`, `targetSegment` 메타 추가.
- 기존 `topic-picker.ts` 패턴 재사용(30일 윈도우 라운드로빈) 또는 리쿠르팅 전용 picker.

### 5.5 어드민 (리쿠르팅 전용 탭)

- Content Hub 헤더 nav에 **"리쿠르팅" 탭** 추가.
- `/admin/content/recruit` — 카드뉴스 검수 목록(기존 cards UI 재사용, 심의필 컬럼 제거)
- `/admin/content/recruit/[id]` — 5장 미리보기(CTA 슬라이드 포함) + 편집 + PNG zip(심의필 제외 5장)
- 리쿠르팅 블로그 검수도 같은 탭 하위 또는 기존 블로그 탭에 `content_type` 필터.

### 5.6 Cron

- `app/api/cron/daily-recruit-card/route.ts` — 리쿠르팅 카드 1세트/일
- `app/api/cron/daily-recruit-blog/route.ts` — 리쿠르팅 블로그 1건/일 (또는 격일)
- 반자동 정책 유지: 자동 발행 X, `status='review'`로 들어와 사람이 검수.

### 5.7 비주얼

- 기존 6스타일(A~F) 재사용. **트렌디 1종(예: 리쿠르팅 전용 굵은 타이포·하이콘트라스트)** 추가 옵션은 Phase 2로 미뤄도 무방.

## 6. Phase 로드맵

- **Phase 1 (지금)**: 데이터 모델 분기 + 리쿠르팅 카드·블로그 생성기 + 가드레일 lint + 앵글 풀 30개 + 리쿠르팅 어드민 탭 + Cron 2개. 기존 6스타일 재사용.
- **Phase 2**: 모션 카드 릴스(반자동 영상 렌더) + 트렌디 비주얼 스타일 + 해시태그/캡션 자동 생성.
- **Phase 3**: 촬영 릴스 운영 가이드 + 세미나 퍼널 + 성과 측정(저장·DM·전환 추적).

## 7. 비기능 요구 / 격리 원칙

- 보험 트랙(insurance)과 리쿠르팅 트랙(recruiting)은 **생성기·lint·주제풀·CTA·DB 구분이 완전히 분리**되어야 한다. 보험 규칙(수치·금액 차단)이 리쿠르팅에 새지 않고, 리쿠르팅 가드레일이 보험에 적용되지 않아야 한다.
- 어드민 UI/PNG export/비주얼 스타일은 공용 재사용하되, 심의필 슬라이드는 리쿠르팅에서 렌더되지 않아야 한다.
- 모든 콘텐츠는 반자동(검수 후 발행).
