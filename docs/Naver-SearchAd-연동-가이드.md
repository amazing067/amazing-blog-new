# 네이버 검색광고(SearchAd) API 연동 가이드

Q&A 글에 넣을 **연관 키워드 5개**를 **네이버 월간검색수** 기준으로 쓰려면 네이버 검색광고 API(키워드 도구)를 연동하면 됩니다.  
아래 순서대로 **한 단계씩** 진행하면 됩니다.

---

## Step 1. 네이버 검색광고 접속

1. 브라우저에서 **네이버 검색광고** 사이트로 이동합니다.  
   - 주소: **https://searchad.naver.com**
2. **네이버 로그인**으로 광고주센터에 로그인합니다.  
   - 이미 검색광고 계정이 있다면 그대로 로그인하면 됩니다.
3. 로그인 후 **관리자센터**로 들어갑니다.  
   - 주소: **https://manage.searchad.naver.com**  
   - 또는 검색광고 화면에서 **관리자센터** 메뉴를 클릭해도 됩니다.

---

## Step 2. API 사용 관리 메뉴 찾기

1. 관리자센터 왼쪽 **사이드 메뉴**를 봅니다.
2. **「도구」** (또는 **「설정」** / **「API」** 등) 항목을 클릭합니다.
3. 그 안에서 **「API 사용 관리」** (또는 **「API 관리」**) 메뉴를 클릭합니다.  
   - 메뉴 이름이 조금 다를 수 있으니, **API** 관련 메뉴를 찾으면 됩니다.

---

## Step 3. API 라이선스 생성

1. **API 사용 관리** 화면에서 **「API 라이선스 생성」** 또는 **「새 API 만들기」** 같은 버튼을 찾아 클릭합니다.
2. 라이선스 이름 등 **필요한 입력란**이 있으면 적당히 입력합니다.  
   - 예: `Q&A 연관키워드용`
3. **생성** 또는 **확인**을 눌러 API 라이선스를 만듭니다.

---

## Step 4. 발급받은 값 3가지 확인·복사

API 라이선스를 만들면 아래 **3가지 값**이 나옵니다. 각각 **복사**해 두세요.

| 값 | 설명 | 우리 프로젝트 환경 변수 이름 |
|----|------|------------------------------|
| **고객 ID** (Customer ID) | 계정/광고주 식별자 | `NAVER_SEARCHAD_CUSTOMER_ID` |
| **액세스 라이선스** (Access License / API 키) | API 호출 시 사용하는 키 | `NAVER_SEARCHAD_ACCESS_LICENSE` |
| **비밀키** (Secret Key) | 서명 생성용 (노출되면 안 됨) | `NAVER_SEARCHAD_SECRET_KEY` |

- **고객 ID**: 숫자 또는 영문+숫자 조합일 수 있습니다.  
- **액세스 라이선스**: 긴 문자열(API 키)입니다.  
- **비밀키**: 한 번만 보여주거나, **다시 보기** 버튼으로 확인할 수 있습니다.  
  - **반드시 이 단계에서 복사**해 두세요. 나중에 다시 볼 수 없을 수 있습니다.

---

## Step 5. 프로젝트에 환경 변수 넣기

1. 프로젝트 **루트 폴더**에서 `.env.local` 파일을 엽니다.  
   - 없으면 새로 만듭니다.
2. 아래 3줄을 **그대로 추가**한 뒤, `=` 뒤에 Step 4에서 복사한 값을 붙여 넣습니다.

```env
# 네이버 검색광고 API (연관 키워드·월간검색수)
NAVER_SEARCHAD_CUSTOMER_ID=여기에_고객_ID_붙여넣기
NAVER_SEARCHAD_ACCESS_LICENSE=여기에_액세스_라이선스_붙여넣기
NAVER_SEARCHAD_SECRET_KEY=여기에_비밀키_붙여넣기
```

3. **따옴표는 넣지 않습니다.**  
   - 예: `NAVER_SEARCHAD_CUSTOMER_ID=12345678` (O)  
   - 예: `NAVER_SEARCHAD_CUSTOMER_ID="12345678"` (X, 가능하면 비추천)
4. 파일을 **저장**합니다.

---

## Step 6. 서버 다시 실행

1. 터미널에서 **개발 서버를 한 번 종료**합니다. (Ctrl+C)
2. 다시 실행합니다.  
   - 예: `npm run dev`
3. 환경 변수는 **재시작해야** 반영됩니다.

---

## Step 7. 동작 확인

1. 앱에서 **Q&A 생성**을 한 번 실행해 봅니다.  
   - 상품명(예: 운전자보험)을 넣고 생성해 보면 됩니다.
2. **연관 키워드 5개**가 결과에 포함되면, 네이버 API가 정상 동작하는 것입니다.  
   - 네이버 키워드 도구와 같은 **연관키워드·월간검색수** 기준으로 상위 5개가 들어갑니다.
3. **연관 키워드가 안 나오거나** 서버 로그에 `[Naver SearchAd]` 관련 오류가 보이면 → Step 8로 넘어갑니다.

---

## Step 8. 403 Invalid Signature 나왔을 때 (비밀키 처리)

API 호출 시 **403 Invalid Signature** 오류가 나오면, **비밀키 형식**이 맞지 않는 경우가 많습니다.

1. 네이버에서 준 **비밀키가 Base64 문자열**인지 확인합니다.  
   - 영문·숫자·`+`, `/`, `=` 로 된 긴 문자열이면 Base64일 수 있습니다.
2. **방법 A — 그대로 쓰기**  
   - `.env.local`에 비밀키를 **그대로** 넣었는데 403이 나온다면, **방법 B**를 시도합니다.
3. **방법 B — Base64 디코딩해서 쓰기**  
   - 비밀키를 Base64 디코딩한 **원본 문자열**을 환경 변수에 넣습니다.  
   - 또는, 우리 코드는 **`base64:` 접두어**를 지원합니다.  
   - `.env.local`에서 다음처럼 수정해 봅니다.  
     `NAVER_SEARCHAD_SECRET_KEY=base64:여기에_발급받은_비밀키_그대로`
   - 이렇게 하면 코드가 비밀키를 Base64 디코딩한 뒤 서명에 사용합니다.
4. 저장 후 **서버를 다시 실행**하고, Q&A 생성으로 다시 확인합니다.

## 참고

- **공식 문서**: https://naver.github.io/searchad-apidoc/
- **API 서버 주소**: https://api.searchad.naver.com
- **키워드 도구**: GET `/keywordstool` (연관키워드·월간검색수 조회)
- 환경 변수를 넣지 않으면 네이버 API는 호출하지 않고, **Google Custom Search** 결과에서 뽑은 키워드 5개를 그대로 씁니다 (동작은 유지됨).

이 순서대로 하면 네이버 SearchAd API로 연동 키워드를 쓰는 설정까지 끝낼 수 있습니다.
