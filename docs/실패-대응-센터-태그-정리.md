# 실패 대응 센터 태그 정리

**목적**: 실패 대응 센터에 나오는 각 태그가 **어디서 판정되는지**, **이미 로직/프롬프트로 어느 정도 막혀 있는지**, **아직 손댈 여지가 있는지** 정리합니다.

- **판정**: `lib/quality-gate.ts`의 게이트 함수들이 생성 결과를 검사한 뒤 `classifyFailureTags()`로 failure 문자열 → 태그 매핑.
- **집계**: `usage_logs.meta.failureTags`를 `api/admin/quality-failures`가 기간별로 집계해 실패 대응 센터에 표시.

## 요약

- **판정**: 전부 **`lib/quality-gate.ts`**의 `gateTitle` / `gateQuestionBody` / `gateAnswer` / `gateThread` / `gateHumanLikeness` / `gateEvidenceConsistency` / `gateKeywordHealth` / `gateOperationalRisk` 중 하나에서 나온 failure 문자열이 **`warningToTag()` → `classifyFailureTags()`**로 태그화됨. `thread_empty`·`operational_final_agent_ending_missing`은 **generate-qa**에서 메타/집계로만 판정.
- **이미 막혀 있는 것**: 프롬프트 길이·톤·역할 지시, **generate-qa** 후처리(`autoSplitQuestionParagraphs`, `normalizeExclamationMarks`, `stripAnswerRoleLeakage`, `normalizeFinalAgentEnding`, `sanitizeCustomerFacingKeyword` 등), 키워드/시장 키워드/concern 로직.
- **손댈 여지**: 게이트 임계값·패턴 목록 확장, 후처리 적용 구간 확대, 재생성/저장 플로우 보강, 제목·첫문장 다양성 강화.

이 문서는 실패 대응 센터 항목별로 **원인(판정 위치)** 과 **대응 상태(막힌 부분 / 남은 개선)** 를 한곳에서 보기 위한 참고용입니다.

## 적용한 개선 사항 (요약)

- **quality-gate.ts**
  - `warningToTag`: "제목이 질문형이 아님", "제목이 마침표로 끝남", "제목에 금지 패턴 포함" → `title_blog_style` / `title_internal_code` 매핑 추가로 `uncategorized_warning` 감소.
  - `gateQuestionBody` formalPatterns: "참고하시기 바랍니다", "안내드립니다", "확인하시면 됩니다" 추가.
  - `gateAnswer` formalWords·docStylePatterns·roleLeakagePatterns: 정리문체/약관체·오픈카톡/연락 유도 패턴 확장.
  - `gateThread` salesPatterns: 오픈카톡, 카톡 문의, 전화/쪽지 주세요 추가.
- **generate-qa/route.ts**
  - `ROLE_LEAKAGE_PATTERNS`: **역할 누수만** 제거(경력/전문가님/설계사입니다). 연락·문의·비교설계 등 CTA는 유입·전환 목적이므로 제거하지 않음.
  - `normalizeFinalAgentEnding`: 영업 문구 제거 없음, 줄바꿈만 정리 (영업성 유지).
  - `normalizeExclamationMarks`: ㅠ/ㅜ/ㅡ 연속 3개 초과 시 앞 2개만 유지 (body_exclamation 완화).
  - 제목 최종 정제 후 40자 초과 시 공백 기준으로 자르기 (title_too_long 방지).
  - `capThreadMessageLength`: 댓글 400자 초과 시 문장 경계에서 자르기 (thread_too_long 방지).
  - 마지막 agent 댓글이 정제 후 비어 있으면 "도움이 되셨으면 좋겠어요."로 채움 (operational_final_agent_ending_missing 방지).
- **quality-gate.ts (영업 목적 반영)**
  - `gateAnswer` roleLeakagePatterns: 연락/문의/비교설계/오픈카톡 등 CTA는 감점 제거. 경력·전문가님·설계사 자기소개만 감점.
  - `gateThread`: 마지막 agent 댓글 영업성 감점 제거 (CTA는 유입·전환 목적).
  - `gateHumanLikeness`: CTA 2회 이상 감점 제거, 6회 이상일 때만 "CTA 과다" 경미 감점.
