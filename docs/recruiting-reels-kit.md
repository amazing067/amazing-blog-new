# 리쿠르팅 릴스 제작 키트 (재사용 공장)

> 목적: 설계사 모집 인스타 릴스를 계속 찍어내되 **메시지(=팩트)는 고정 스파인으로 재사용, 스타일(=포맷·연출)은 매번 갈아끼워** 질리지 않게.
> 영상 생성: **Seedance 2.0**(Dreamina 웹) · 영화급 히어로컷만 **Veo 3.1**.
> 편집: **프리미어 프로**(사용자 주력 툴). 생성 클립을 프리미어로 가져와 자막·컷·색보정·9:16 마감.
> 3대 메시지(고정 스파인): ①높은 수수료(투명·공정) ②시스템5 차별점 ③워라밸(DB영업·콜드콜 X) — 셋 다 핵심.
> 톤: 병맛(후킹·조회수) / 영화(신뢰·전환) 두 버전 병행.
>
> ⚠️ **이 키트의 사용법(중요)**: 아래 ①②③ 메시지·팩트·마스코트는 **고정**(검증된 무기라 안 바뀜). 바꾸는 건 **6번 "바이럴 포맷 로테이션"의 연출 틀**. 즉 "같은 메시지를 매번 다른 바이럴 포맷에 태운다" = 신선함 + 일관된 무기. 메시지를 바꾸는 게 아니라 **포맷을 바꿔서** 질림을 막는다.

---

## 0. 절대 규칙 (매번 지킬 것)

1. **한글 자막은 AI로 생성하지 말 것.** Seedance/Veo는 한글 글자를 깨뜨림 → **영상엔 글자 없이 뽑고, 자막은 CapCut에서 직접 입력.**
2. **마스코트는 "락 프롬프트"를 매 컷 그대로 복붙** → 같은 시바가 나옴(일관성).
3. **과장 금지** (레퍼런스 규정): 수입은 "성과에 따라 / 상위 사례 / 범위"로만. "메리츠 자동화"는 미완 → 언급 금지.
4. **영화룩 = 조명 90%.** 프롬프트에 cinematic / shallow depth of field / film grain / golden hour 필수.
5. 9:16 세로, 15초 기준(릴스 최적). 첫 1초에 훅이 안 터지면 다 무의미.

## 6. 바이럴 포맷 로테이션 뱅크 ★ (질림 방지의 핵심)

> 2026 트렌드 리서치 기반. **메시지는 고정, 이 "포맷"을 매번 바꿔서** 같은 무기를 새 옷에 입힌다.
> 규칙: 첫 1초 훅 / 7~19초 / 무한루프 / 비트매칭 / 자막 ON / 날것(raw)감 > 과한 연출.

| # | 포맷 | 어떻게 | 우리 메시지에 적용 예 |
|---|---|---|---|
| F1 | **결과 먼저(Payoff-first)** | 0초에 충격 결과부터 보여주고 "어떻게?"로 끌기 | "설계사 첫 달, 명단이 자동으로 쌓였다" 보여주고 → DB 자동배정 설명(③) |
| F2 | **질문 훅** | 답이 궁금해 끝까지 보게 | "수수료가 어디서 새는지 아세요?" → 모수 100% 공개(①) |
| F3 | **긴급/타이밍 훅** | "지금 이걸 봤다고?" 류 다급함 | "지인 영업 한계 느낄 때 이거 못 봤으면 큰일날 뻔"(③) |
| F4 | **다중 페르소나 토론** ⤴급상승 | 한 화면에 여러 캐릭터가 같은 주제로 티키타카(마스코트 2~3마리) | 회의적 시바 vs 시스템 자랑 시바 → 시스템5 디베이트(②) |
| F5 | **Day-in-the-life** | 설계사/마스코트 하루 따라가기(날것감, 채용에 최강) | 마스코트의 하루: 출근(Check)→DB확인(Server)→상담→칼퇴(③) |
| F6 | **"입사 전 몰랐던 것"** | 후배에게 솔직 꿀팁 주는 톤 | "설계사 시작 전 알았으면 한 것: 회사가 시스템을 만드는지 봐라"(②) |
| F7 | **알고리즘 테스트 밈** | "공들인 편집 vs 그냥 서있기, 뭐가 더 잘됨?" 셀프 디스 | 화려한 시스템5 그래픽 vs 시바 멍때림 → 병맛(②) |
| F8 | **통념 부수기(Myth)** | "다들 ○○라는데 사실은…" 트렌드 사운드 위에 | "보험영업=지인팔이? 우린 콜드콜 안 함"(③) |
| F9 | **비포→애프터** | 좌절 상태 → 시스템 만난 후 반전 | 텅 빈 연락처(before) → 자동 명단(after)(③) |

**조합 매트릭스**: 메시지 3 × 톤 2 × 포맷 9 = **54가지** 서로 다른 릴스가 한 키트에서 나온다. 같은 ①수수료 메시지여도 F2(질문훅)·F4(토론)·F9(비포애프터)로 매번 완전히 달라 보임.

> ⚠️ 알고리즘 2026: **저장·공유 > 좋아요**. 똑같이 베끼면(리포스트·워터마크·유사복제) 페널티 → 그래서 포맷 로테이션이 전략적으로도 맞음. 트렌드 오디오 쓰면 참여 +42%.

## ★ 처음부터 하는 법 (가입 → 생성 → 프리미어 마감)

### STEP 0 — 준비물 (한 번만)
- [ ] **마스코트 마스터 이미지 1장** 확정 (일관성의 기준). 기존 검증 레퍼 `public/_hybrid/A-3.jpg` 사용 가능. 없으면 Nano Banana 2로 깔끔한 정면 1장 먼저 확보.
- [ ] 프리미어 프로 설치 확인.

### STEP 1 — Dreamina(Seedance) 가입
1. **dreamina.capcut.com** 접속 → 구글 계정으로 로그인(영문 인터페이스 권장).
2. 크레딧/요금제 확인 (무료 크레딧으로 테스트 → 부족하면 월 구독).
3. 메뉴에서 **AI Video** (또는 Image-to-Video) 선택, 모델 **Seedance 2.0** 지정.

### STEP 2 — 컷 생성 (C1~C6 반복)
1. **Image-to-Video 모드**에서 마스코트 마스터 이미지 업로드 (← 컷마다 같은 시바가 나오는 비결).
2. 위 프롬프트 1개 붙여넣기 → **비율 9:16**, **길이 3~5초** 설정 → 생성.
3. 마음에 들 때까지 2~3회 재생성(seed 다르게). 한글 글자 나오면 버리고 재생성("no text" 강조).
4. 컷별로 다운로드 → 한 폴더에 `C1.mp4 … C6.mp4`로 저장. (워터마크는 유료 플랜에서 제거)
5. (선택) C5 퇴근 히어로컷만 **Veo 3.1**로 더 영화같이.

### STEP 3 — 프리미어 프로 마감
1. 새 프로젝트 → 시퀀스 **1080×1920(9:16)**.
2. C1~C6 순서대로 타임라인에 배치, 각 컷 길이 표대로 트림.
3. **자막**: 위 표의 한글 자막을 .mogrt(또는 에센셜 그래픽)로 입력. 굵게+외곽선, 안전영역 안.
4. **BGM** 깔고 마커로 비트 찍기 → 비트에 컷 맞추기.
5. **Lumetri**로 .cube LUT 하나 만들어 전 컷에 적용(톤 통일 = AI 티 감소).
6. **무한루프**: C6 끝 ↔ C1 시작이 부드럽게 이어지게 미세 조정.
7. **CTA** .mogrt 끝 2초 고정.
8. 내보내기: H.264, 1080×1920, 고비트레이트 → 인스타 릴스 업로드.

### STEP 4 — 업로드 후
- 7번 실험 로그에 1줄 기록(조회/저장/공유/DM).
