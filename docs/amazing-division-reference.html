어메이징사업부 시스템·팩트
리쿠르팅 메시지 레퍼런스

영업은 재능 + 시스템입니다

입사설명회 PPTX(심플버전=정제 최종본) + 실제 코드베이스 분석 기반 · 콘텐츠 자동생성의 사실 근거 자료

이 문서의 용도 — 리쿠르팅 카드·블로그·릴스를 만들 때 "무엇이 진짜 특별한가"의 근거. 핵심 결론: 어메이징의 복제 불가능한 무기는 자체 개발한 시스템 생태계다. "교육·멘토 / 고객DB / 전문성 / 수수료" 같은 일반 GA 메시지가 아니라, 아래 시스템·팩트로 말해야 차별화된다.

01핵심 메시지

모든 리쿠르팅 콘텐츠가 수렴해야 할 한 문장과 그 증거 구조.

"영업은 재능이 아니라 시스템이다."
타사가 외주로 빌려 쓰는 도구를, 어메이징사업부는 직접 만들고 매주 업데이트한다 — 외주 0, 빌려 쓰는 SaaS 0. 신입도 10일 온보딩이면 이 시스템 전부를 손에 쥐고 실전 투입된다.

시스템이 "어떻게 영업하나"라면, 회사는 "오래 함께할 수 있나". 모두 공시·규정집 기반.

축팩트

투명성수수료 모수 100% 공개 · 시책 본사 책임지급 · 실시간 확인(PAMS)
공정성학연·지연 아닌 규정집 기반 승격(팀장 5천만/지사장 4억/본부장 12억) · 분할수수료 · OR(오버라이딩)
정직함"부풀린 1위보다 정직한 5위" — 실활동 인원 8,673명(비활동 코드 제외, 자회사형 제외 시 독립 4위)

출처: 금융감독원 · 법인보험대리점 통합공시(2024~2025년 기준) / 회사 공식 소개. 수수료·시책 예시 수치는 상품·실적·차수에 따라 달라짐.

05리쿠르팅 메시지 가이드

위 팩트를 카드/블로그/릴스에 쓸 때의 방향과 안전선.

강점 카드 — 권장 방향 (제안)

기존 "교육·멘토 / 고객DB / 전문성 / 투명수수료 + 01~04 숫자" = 일반 GA 메시지라 약함.
→ "직접 만든 시스템 5개"를 강점 카드의 주인공으로. 코드네임(영문 모노) + 한 줄 기능. 숫자·사물 아이콘 대신 제품 코드네임이 테크 신뢰감을 만든다.
· 5개를 다 보여줌(추리지 않음 — "5개·외주 0"이 펀치). · 레이아웃: 2×3 = 시스템 5칸 + "외주 0·전부 자체개발" 선언 1칸(빈칸 없이 꽉 참). · 데이터는 AI 생성 금지 → 고정 팩트뱅크(시스템명·기능은 사실, 할루시 차단).

가드레일 (직업안정법·금소법·섀도우밴 — recruit-lint과 동일선)

  • 금지 "고수익 보장 / 월○○ 확정 / 무조건" → 직업안정법 제34조
  • 금지 외제차·명품·트로피 인증 → 2030 다단계 연상
  • 금지 연락처 + 구체 수익 동시 노출 → 금소법 업무광고
  • 권장 "성과에 따라 / 상위 사례 / 범위" + "DM 문의" · 시스템·팩트로 증명
어메이징사업부 내부 레퍼런스 · 분석일 2026-05-27 · 근거: 입사설명회(최신/심플버전) PPTX + 6개 시스템 레포 코드 분석.
이 문서는 사실 정리용이며 그대로 외부 광고에 쓰지 말 것 — 카드/블로그는 가드레일을 거쳐 발행한다.
